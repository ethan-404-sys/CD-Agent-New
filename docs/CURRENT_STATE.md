# CD-Agent 项目当前状态与阶段路线说明

> **文档定位**：本文档记录组会讨论确立的最新研究主线、架构边界与下一阶段执行计划，作为后续开发与实验调度的单一基准状态（覆盖更新，不追加历史流水账）。

## 一、项目结构与任务体系简述

### 1.1 研究核心定位

**CD-Agent** 是面向高分辨率遥感双时相变化检测的**闭环迭代智能体系统**。系统接收双时相遥感输入（$T_1, T_2$）、自然语言指令及可选的视觉参考、空间约束或初始掩码，输出精细二值变化掩码、统计摘要与可解释轨迹。

项目的核心立论已由早期的“免训练开环工具流拼接”正式升级为**“多任务自适应验证驱动的掩码持续闭环优化”**：获取初始变化掩码为基础能力，通过规划器与验证智能体的非对称协同持续消除**误检、漏检与边缘缺陷**为核心创新点。

### 1.2 系统核心模块架构

| 模块名称 | 代码/角色定位 | 当前状态与核心职责 |
| :--- | :--- | :--- |
| **Planner（规划智能体）** | `planner.py` / VLM | 解析复杂任务意图与空间/语义约束，按需调度分割、跨期匹配、OSM 先验查询及单期局部精修工具，拥有掩码修改执行权。 |
| **Harness & Session** | `loop_json.py` | 负责步数预算控制、参数校验与句柄状态隔离（避免原始张量撑爆上下文）；拟新增“迭代优化开关”（关闭时单轮出初筛掩码，开启时进入闭环精修）。 |
| **Toolbox（原子工具箱）** | `tools.py` | 提供 `view`、`inspect`、`segment_text`（SAM 3）、`match_instances`、集合与形态学运算、`add_region`、`remove_region`、`refine_region` 及历史 OSM 检索等原子工具。 |
| **Verifier Agent（验证智能体）** | 待升级改造核心 | 独立于规划器的审查智能体（只读不写）。内部挂载**受训多任务空间诊断模型**与**轨迹合规审查逻辑**，联合输出错漏定位与流程修正意见，并掌管闭环终止放行权。 |
| **Recorder / Replay** | `recorder.py` | 独立记录完整对话、工具轨迹、中间掩码句柄与评测指标（如 $F_1^c$），物理隔离真值以杜绝推理泄露。 |

### 1.3 任务矩阵调整现况（4 类一级场景与多维约束）

* **横轴主任务缩减为 4 大一级场景**（原 $T_2$ 整体并入 $T_3$ 视觉参考下，保留既有任务编号以便代码与实验对齐）：
  1. **常见类别（$T_1$）**：用户在指令中显式指定基础视觉模型可识别的单类或多类地物变化；
  2. **视觉参考（$T_3$，收编原 $T_2$）**：基于图内或跨图视觉示例定义目标变化，涵盖拿稀缺类别图像作为视觉参考、并由 Agent 协同调用历史 OSM 获取空间语义先验的任务；
  3. **描述定义（$T_4$）**：通过外观属性、功能特征或空间关系推理定义目标变化；
  4. **掩码优化（$T_5$）**：基于已有初始结果或交互反馈发现错误并持续迭代修正（全面覆盖误检剔除、漏检召回与边缘优化），含旧地图更新。
* **纵轴附加约束（$C_0 \sim C_4$）**：无约束（$C_0$）、变化方向/转换/程度（$C_1$）、空间范围（$C_2$）、排除条件（$C_3$）及多条件组合（$C_4$）。
* **多源输入扩展**：在默认“光学—光学”基础上，优先探索“地图—影像”与“跨模态异源影像（如光学—SAR）”输入场景。
* **远期储备任务**：变化视觉问答（Change VQA）与变化描述（Change Captioning）记录在册作为掩码收敛后的下游拓展，暂不纳入下一阶段主攻范围。

## 二、组会核心指示与路线纠偏

1. **严守数据复用原则，拒绝重头造数据**
   优先复用公开标准数据集（LEVIR-CD、SECOND、WHU-CD 等）以及课题组师兄已整理的现成数据（含跨模态配准数据、SECOND 建筑属性标注等）；仅在必要局部做极轻量补充，绝不投入高昂人力重造大规模数据集。

2. **跨模态任务早测早决，聚焦优势长板**
   下一阶段尽早摸底跨模态异源数据任务，重点验证智能体与现有工具链能否有效跑通；若经过几轮迭代仍受限于底层感知瓶颈、表现不佳，则交给 Ethan 来判断，是否裁剪该类任务，集中精力放大核心优势板块。

3. **剥离工程化补漏补丁，重构“真验证器”定义**
   此前的多源补漏工具（`find_missed`）本质属于工程规则补丁，缺乏算法级创新，后续统一移交至**固定流程基线（Fixed Pipeline Baseline）**作为对照。真正的验证器不能只对已有候选切片做局部二分类，必须联合接收双时相图像、现有掩码与任务约束，自主定位全局**误检区、漏检区与边缘残缺区**。

4. **跳出简单工作流拼接，确立三大核心创新点**
   单纯“大模型调工具 + 零样本核验”易沦为常规工程，提取技能（Skills）仅作为锦上添花的辅助手段。论文核心创新收拢为三点联动：
   * **基准任务创新**：面向开放指令、视觉参考、多维约束与多源输入的交互/自主变化检测任务体系；
   * **智能体架构创新**：“规划智能体 + 验证智能体”非对称双智能体闭环，实现“生成 $\to$ 审查 $\to$ 反馈 $\to$ 修正”的持续掩码优化（覆盖误检剔除、漏检召回与跨时相边缘精修）；
   * **验证器算法创新**：面向多任务约束自适应的空间错误诊断模型，摆脱单一固定任务判别局限（“变化分析”仅作为极端情况下的备选退路）。

## 三、下一阶段核心工作方向

### 方向一：$T_3$ 视觉参考系列开发集搭建与轨迹审查（核心必保任务）

* **重要性与目标定位**：$T_3$ 视觉参考系列任务（含并入的稀缺类视觉参考 + OSM 协同）是本工作的核心特色板块，需尽快搭建可靠开发集并持续推进测试，尽早拿到可验收的初步结果。
* **数据构建人工把关**：前期预处理的任务数据经初步审查仍存在质量问题（具体问题后续专项梳理解决），下一阶段由 Ethan 亲自把关开发集的样本筛选与构建标准，确保视觉参考指代清晰、真值准确无歧义。
* **持续测试与轨迹审查**：在把关后的开发集上快速迭代 Agent 测试，由 Ethan 深度审查模型真实工具调用轨迹与中间掩码状态，定位并打通视觉参考检索与判别链路。

### 方向二：多源异构输入任务摸底测试（考察 Planner 规划边界）

* **实验配置**：**暂时冻结当前零样本 VLM 验证器（`ask`）**，不引入重型验证改动，控制变量单独评估 Planner 在异源场景下的理解、选工具与跨期推理能力。
* **测试重点**：接入组内现成的跨模态数据（如灾前光学与灾后 SAR、历史矢量地图与最新光学影像），观察 Planner 能否识别传感器差异（例如规避光学分割工具在 SAR 图上的失效，自主选择光学时相提取轮廓或调用适配工具）。
* **准入裁决**：设定小规模快速试跑轮次上限，根据真实轨迹与初始掩码质量完成“保留深挖”或“果断删除”的决策。

### 方向三：验证器的 Agent 化升级与闭环构建（分两步走）

#### 第一步：训练多任务自适应的空间诊断模型（算法底座，最新路线调整）

* **数据集聚焦 `SECOND`**：放弃 `LEVIR-CD` 与 `WHU-CD` 作为验证器训练主战场（二者本质偏向单类建筑分割、已有 IoU 过高，做验证增益意义有限），现阶段**集中精力把 `SECOND` 单数据集做透**（多语义类与有向转换 `related / into / outof / transition` 才是多任务自适应验证的核心检验场）。
* **架构转向“放开特征提取器微调 + 改造 SAM / SAM3 注入 Mask 分支”**：否定“完全冻结 DINOv3 + 轻量头”作为首选（遥感多类别变化需要放开特征提取器做领域适配）。主路线确立为**基于 SAM / SAM3 改造，将当前待审掩码 $M_t$ 作为新分支/密集提示注入，并放开视觉编码器微调**；具体基座选型（SAM 1 vs SAM 3）及微调方式（全参微调 vs LoRA/Adapter）结合相关论文调研后定型（原冻结 DINOv3 仅降级为可选对照消融）。
* **统一输入表征与诊断输出**：输入包含双时相影像 $(T_1, T_2)$、当前待审变化掩码 $M_t$ 及任务条件 $Q$；首版聚焦预测**空间互斥的误检区域（FP，$M_t$ 内）与漏检区域（FN，$M_t$ 外）及全局收敛分**（严格保留 $T_1 \to T_2$ 有向差异，屏蔽 `ignore_mask`；时相归因与边缘通道视闭环首版瓶颈再决定是否增量引入）。
* **数据规模与高质量初始掩码建设**：
  1. **数据量按可学习参数量定型**：摒弃早期 600 对底图够用的假设，参考微调 SAM 相关论文做法，结合微调参数规模充分利用 `SECOND` 官方训练集（2968 对底图）与多任务组合构造足量训练样本，严格保持源图级 `train / val / test` 隔离；
  2. **引入微调模型提升初始掩码质量**：除免训练开放词汇方法外，在 `SECOND` 训练集上引入**微调过的有监督/同域模型**跑出一批高质量初始掩码（不担心训练集同源泄露），覆盖低/中/高分全难度档，并继续结合集合差监督（$Y_{\text{FP}} = M_t \setminus G_Q$，$Y_{\text{FN}} = G_Q \setminus M_t$）与**同图跨任务反事实采样**强化多任务区分力。

#### 第二步：封装轨迹感知的验证 Agent，打通迭代优化闭环（系统架构）

* **双重审查职能**：验证 Agent 在 Planner 提交初始掩码后介入，一方面调用上述**受训空间诊断模型**获取像素级错漏与边缘缺陷位置，另一方面**综合审查 Planner 的完整执行轨迹**（核查是否漏掉空间框裁剪、方向过滤、多类别合并或 OSM 先验检索等程序性步骤）。
* **非对称闭环协同**：验证 Agent 汇总像素诊断与轨迹审查结论，向 Planner 返回结构化返工指令；Planner 据此调整工具参数、剔除误检、回对应时相补漏或调用局部修边工具（`refine_region`），直至验证 Agent 判定收敛通过并输出最终掩码。
* **不设兜底护栏，直接暴露真问题**：现阶段闭环实现**暂不添加人工防退化回滚等保护性补丁**，允许初期形态粗糙，让诊断模型、反馈传递与规划器重修过程中的真实缺陷直接暴露出来，以便针对性迭代核心算法。
* **系统级对比支撑**：固定流程基线同步并入旧版 `find_missed` 补漏规则，与开启闭环优化开关的完整双智能体系统展开公平对比。

## 四、已讨论的核心参考论文清单

### 4.1 闭环视觉智能体与非对称审查架构

1. **CLOVA (CVPR 2024)** — *CLOVA: A Closed-Loop Visual Assistant with Tool Usage and Update*
   * **借鉴点**：“执行 $\to$ 视觉验证 $\to$ 错误归因 $\to$ 参数重调”闭环范式，指导验证反馈如何反向驱动上游工具阈值与提示词更新。
2. **Critic-V (CVPR 2025)** — *Critic-V: VLM Critics Help Catch VLM Errors in Multimodal Reasoning*
   * **借鉴点**：将推理规划器与专用受训审查器（Critic）非对称解耦，克服单一模型自我反思（Reflexion）时的确认偏见与双智能体功能重复。
3. **SegAgent (CVPR 2025)** — *SegAgent: Exploring Pixel Understanding Capabilities in MLLMs by Imitating Human Annotator Trajectories*
   * **借鉴点**：模仿人类标注员“看错漏 $\to$ 局部交互修补 $\to$ 收敛停止”的序贯轨迹，契合掩码持续迭代优化开关的设计。
4. **Visual Sketchpad (NeurIPS 2024)** — *Sketching as a Visual Chain of Thought for Multimodal Language Models*
   * **借鉴点**：将中间掩码与诊断框渲染为视觉思维链，优化多轮迭代中验证 Agent 与规划器之间的视觉上下文传递。

### 4.2 空间错漏诊断、条件注入与边缘精修算法

5. **PseudoClick (ECCV 2022)** — *PseudoClick: Interactive Image Segmentation with Click Imitation*
   * **借鉴点**：将原图与现有粗糙掩码联合输入密集网络，显式预测误检图（FP Map）与漏检图（FN Map）并生成修正锚点，是受训诊断模型的最直接原型。
6. **LISA (CVPR 2024)** — *LISA: Reasoning Segmentation via Large Language Model*
   * **借鉴点**：将复杂自然语言约束编码为特征向量并通过交叉注意力注入密集掩码解码器，支撑“多任务语义条件化”的自适应验证。
7. **SegRefiner (NeurIPS 2023)** — *SegRefiner: Towards Model-Agnostic Segmentation Refinement with Discrete Diffusion Process*
   * **借鉴点**：模型无关的粗糙掩码错漏与边缘联合优化框架，其“真实模型残差 + 形态学合成扰动”的数据构造法可直接用于训练验证器。
8. **CascadePSP (CVPR 2020) & FocalClick (CVPR 2022)**
   * **借鉴点**：局部高分辨率窗口裁剪与精细贴边机制，直接对应边缘误差诊断后的局部单期修边（Edge Optimization）流程。

### 4.3 遥感变化检测智能体与多维基准

9. **Change-Agent (IEEE TGRS 2024)** — *Change-Agent: Toward Interactive Comprehensive Remote Sensing Change Interpretation and Analysis*
   * **借鉴点**：遥感变化检测首篇开环工具路由工作，可作为论文引言中凸显“闭环持续掩码优化”与“轨迹审查”必要性的直接对比靶子。
10. **Referring Change Detection (WACV 2026)** — *Referring Change Detection in Remote Sensing Imagery*
    * **借鉴点**：自然语言属性与变化方向指代下的变化检测任务定义与前沿基线，对标 $T_1 \times C_1$ 与 $T_4$ 描述约束任务。
11. **AnyChange (NeurIPS 2024)** — *Segment Any Change*
    * **借鉴点**：零样本双时相特征匹配与图内点选交互基线，双时相特征交互方式亦可供诊断模型编码端参考。
12. **LaVIDE (IEEE TGRS 2025) & ThinkGeo (2025)**
    * **借鉴点**：前者提供矢量地图与光学影像跨模态对齐思路（支撑 $T_{5.4}$ 与 OSM 联动），后者提供遥感多步工具调用轨迹的定量评测指标参考。
